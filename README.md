# 판 뒤집기

근미래 서울(2031년)을 배경으로 한 법정 추리 게임. 타이틀의 **사건 기록부**에서 에피소드를 골라요.

**제1화 「무인(無人)의 밤」** (약 50~60분, 법정 하루): 무인 편의점 창고에서 점주가 숨지고, 감시 AI가 "상품 무단 반출"로 찍은 야간 관리원이 피고인이 된다. 범인을 먼저 보여 주는 프롤로그로 시작하는 튜토리얼 에피소드. 기록은 법정에서 검사가 법정 화면에 하나씩 띄우며 넘겨주고, 시스템은 처음 쓰일 때 안내 카드로 알려 준다. 재판은 세 공방(창고에 있던 사람은 태오뿐이었나 · 봉지에는 무엇이 들어 있었나 · 머리 치명상은 언제, 그때 태오는 어디)으로 나뉜다. 녹음기가 담은 첫 폭행을 사망 순간으로 읽었다가, 범인의 부분 자백으로 그 가설이 무너지고, 같은 기록을 다시 읽어 112 신고 중의 가해를 밝힌다. 마지막 입증은 감정 결과(무엇) · 112 현장 공유 사진(언제) · 녹음기와 도어락(그때 피고인은)의 세 자료로 쌓는다. 논리 설계와 정답 처리표는 `docs/ep1-rewrite.md`(개정 EP1-R4).

1. 프롤로그 「그날 밤」: 감시 카메라 화면과 범인 시점, 첫 폭행까지 (약 3분)
2. 국선변호인 사무실에서 강단비 소개(국선전담변호사, 아버지 사건과 판관 예측) → 피고인 접견실 비공개 면담: 나래, 태오, 구만두, 엄정한 첫 등장. 나래의 셔터 사진이 첫 증거
3. 개정: 법정 화면으로 아이가드 · 판관 · 재판장의 역할 → 검사 모두진술(인물 카드, 평면도, CAM1·CAM3, 상처 도식, 112 통화, 현장 공유 사진, 가방 속 상패, 사실과 주장을 나눈 동선) → 제1 공방: 구만두의 사건 개요(튜토리얼) → 목격자이자 신고자 오정택의 "봤다", "들었다"
4. 휴정 → 제2 공방: 조말순 할머니, 증거대의 봉지를 직접 살펴 녹음기 발견, 녹음기 재생(가짜 승리)
5. 오정택의 「녹음 속 사람」 → 스마트워치 → 첫 폭행 인정 → 점심 휴정
6. 제3 공방: 도어락 → 「남은 시간」 → 통화 중 피고인은 어디에(두 녹음 짝짓기) → 「상패와 머리 손상」 → 대조 감정 대기
7. 오후 4시 감정 결과 → 감정서의 결정적 문장 · 사진에서 모서리와 10초 구간 찾기 · 그때 피고인 → 먼저 쓰인 설명 → 진범 붕괴 → 무죄 → 에필로그

**제4화 「대체된 증인」** (약 40분, 조사 + 법정 3일): 누리랩 조사 → AI 증인 다온 → 박하은 → 서지훈 신문, 진범 붕괴, 무죄, 에필로그.

공개 빌드에서는 제1화만 플레이할 수 있고 제2~4화는 "준비 중"으로 나와요. 제4화 대본은 공개 빌드에서 제외되며 `?ep=4`로도 열리지 않아요. `npm run dev`로 실행하는 로컬 개발 환경에서는 제4화도 플레이할 수 있어요.

## 실행

스마트폰에서는 **가로 모드**로 플레이해요. 세로 화면에는 회전 안내가 나오며, 가로로 돌리면 진행하던 화면이 그대로 돌아와요. 모바일에서는 대사·선택지·기록을 크게 표시하고, 버튼과 화면 위쪽 표시는 데스크톱과 같은 모양 그대로 1.5배로 키워요. 키보드 단축키 표시는 숨기고, 터치할 때 생기는 파란 강조도 나오지 않아요. 브라우저 주소창과 노치 영역에 맞춰 화면 크기를 조정해요. 지원하는 브라우저는 설정에서 **전체 화면**을 선택할 수 있어요.

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:5173`을 열면 돼요.

## 조작

| 키 | 하는 일 |
|---|---|
| 클릭 · Enter · Space | 다음 대사 |
| Q | 흔들기 (증언을 캐묻기). 흔든 뒤에는 다음 증언으로 넘어가요 |
| H | 힌트. 1화는 힌트 창이 열리고 한 번 더 누를 때마다 다음 단계(쟁점 → 자료 → 구체적으로). 4화는 반대신문 힌트가 막연한 것부터 차례로 |
| E | 증거 제시 |
| ← → | 증언 이동 |
| R | 법원기록 보기 |
| L | 대사 기록 (지나간 대사 다시 보기) |
| O | 설정 (대사 속도, 음악·효과음 크기) |
| M | 소리 켜기·끄기 |
| 1~4 | 조사 메뉴(조사·이동·대화·제시)나 선택지에서 고르기 |
| ↑ ↓ · 숫자 → Enter | 선택지는 처음엔 아무것도 골라져 있지 않아요. 고른 뒤 Enter(또는 같은 칸을 한 번 더 클릭)로 정해요. 정답이 없는 진행 메뉴는 클릭·숫자 한 번이면 돼요 |
| 짝짓기 화면 | ↑ ↓ 줄 바꾸기, ← → 고르기, Space(또는 클릭)로 놓기, Enter 확인 |
| 사진 단계 | 클릭 또는 ← → · Enter로 부분 지목, ← → · Space(또는 클릭)로 사진 두 장, Enter 확인 |
| 한 화면 조사 (1화 봉지) | 클릭, 또는 ← → 로 고른 뒤 Enter. 찾을 것을 찾을 때까지 나갈 수 없어요 |
| 안내 카드 | Enter(또는 「알겠어요」)로 닫아요 |
| Tab | 법원기록에서 증거 ↔ 인물 ↔ 메모 탭 바꾸기 |
| Space (법원기록) | 고른 증거의 평면도·사진 크게 보기. 증거 제시는 Enter나 E |
| Esc | 조사·목록·법원기록·사진·힌트 창 닫기 |

선택지와 증거 제시 화면은 키 반복과, 화면이 열릴 때 이미 눌려 있던 키를 무시해요. 대사를 Enter로 넘기다 답을 우연히 고르지 않게요.

## 대본 쓰는 법

```ts
say('eom', '반박의 여지가 없는 기록입니다.'),
say('dan', '그 사원증은 {r}회사 안에{/} 있었어요!', 'point'),   // {r}…{/} 빨간 강조, 마지막 인자는 표정
think('(…뭔가 이상해.)'),                                     // 주인공 속마음 (파란 글씨)
shout('objection'),                                            // 이의 있음! / holdit 잠깐! / takethat 받아라!
```

증언 한 줄에는 `press`(흔들었을 때 대사), `accept`(모순이 되는 증거나 인물), `nearMiss`(아깝지만 오답일 때 힌트, 감점 없음)를 달 수 있어요. 지적 자체는 맞는데 아직 결정타가 아닐 때는 `nearMiss`에서 그 지적을 먼저 인정하고 `memo()`로 남긴 다음, 남은 질문을 짚어 주세요. 필요하면 `reveal()`로 증언을 고쳐 말하게 하고, `flag()`·`when()`으로 뒤의 대사가 그 사실을 기억하게 해요(1화 「상패와 머리 손상」에서 현장 공유 사진을 먼저 낸 경우의 `ep1:plateWindow`). `accept`에 인물 id(예: `'seo'`)를 넣으면 법원기록의 "인물" 탭에서 그 사람을 제시해야 해요. 숨겨진 증언(`hidden`, `replaces`)은 흔들기 도중 `reveal()`로 드러나요.

## 조사 파트 쓰는 법

장소 하나는 이렇게 생겼어요 (`src/content/investigation.ts`).

```ts
callcenter: {
  name: '고객센터',
  bg: 'callcenter',                 // src/assets/bg/callcenter.png
  person: undefined,                // 그 장소에 있는 사람. 있으면 대화하기·제시하기가 켜져요
  connects: ['lobby', 'serverroom'],
  enter: [...],                     // 처음 도착했을 때 한 번만
  hotspots: [
    { id: 'ramen', label: '컵라면', x: 935, y: 438, w: 145, h: 112,   // 1280×720 기준 좌표
      script: [..., flag('f_ramen')],
      again: [...] },               // 두 번째부터
  ],
  talks: [{ id: 'nightshift', label: '밤에 일하는 사람', requires: 'f_ramen', script: [...] }],
  presents: { cardReturn: [...] },  // 증거별 반응
}
```

- `addEvidence('id')` — 증거를 법원기록에 넣고 알림을 띄워요
- `flag('이름')` — 진행 상황을 기록해요. `requires`나 `when()`으로 확인해요
- `when('id', [있을 때], [없을 때])` — 플래그나 증거를 가졌는지에 따라 갈라져요
- `addProfile('id')` — 나중에 등장하는 인물(`later: true`)을 법원기록에 넣어요
- `field('lounge')` … `field(null)` — 메뉴 없이 법정 밖 장소(대기실 등)를 보여 줬다가 법정으로 돌아와요
- `zoom` · `redflash` — 진범이 무너질 때처럼 카메라를 당기고 화면을 붉게 번쩍여요
- `verdict('무죄', true)` — 판결을 한 글자씩 찍고, 무죄면 색동 꽃가루와 환호가 터져요
- `investigate('lobby', [목표들], [끝날 때 대본])` — 목표(증거·플래그)를 전부 모으면 조사가 끝나요

**1화 개정(EP1-R4)에서 추가한 연출**

```ts
panel('이 법정에서, 누가 무엇을 하나', [                // 법정 화면(홀로그램 패널)에 카드 한 줄
```

- `card`의 `img`는 `'profile:<인물id>'`, `'char:<캐릭터id>'`(그림에서 얼굴만), `'item:<증거id>'`, `'icon:iguard'`·`'icon:pangwan'`, `'figure:<도식id>'`. `tone`(`fact`·`claim`·`ai`·`person`·`pending`)은 색이고, `tag`는 그 색을 글로도 적어요.
- `route`의 종류: `fact`(기록이 보여 주는 이동, 실선) · `unseen`(아무 기록도 없는 구간, 흐린 점선) · `claim`(누군가의 주장, 빨간 점선). 넷째 인자는 라벨의 왼쪽 위치(평면도 좌표).
- `guide`의 넷째 인자: `'gauge'`(판관 예측) · `'chances'`(재검토 기회) · `'tools'`(법원기록 버튼 줄).
- `guide`의 줄에 키보드 키(`[Q]` 등)를 쓰면 `keys('걸리는 말에는 [Q] 흔들기.', '걸리는 말에는 「흔들기」.')`처럼 휴대폰에서 보일 문구를 함께 적어요. 키보드가 없는 휴대폰에서는 둘째 문구가 나와요. `[확인]`처럼 키가 아닌 표지는 그대로 써도 돼요.
- `examine`은 메뉴 없는 한 화면 조사예요. 넷째 인자(플래그나 증거 id)를 가질 때까지 계속 고르게 하고, 그동안 인물 그림은 숨겨 목소리만 나와요. 조사 지점 좌표는 1280×720 기준이고, `?spots`로 테두리를 볼 수 있어요.
- 증거에 `figure: 'injury'`를 달면 법원기록의 요약 아래에 그 도식이 나와요(1화 부검 소견서). 도식의 바탕 그림은 Codex가 그린 `src/assets/photos/injury-chart.png`이고, 번호 고리 자리는 `engine/figures.ts`의 좌표예요.
- 증거나 인물을 받으면 그림 카드가 화면 가운데에 크게 뜨고(`showReceived`), 대사창에 이름과 「확인되는 것」 첫 줄이 나와요.
- 얼굴 사진(법원기록 인물 탭, 법정 화면 카드)은 `characters.ts`의 `face: [x, y, 확대]`로 캐릭터마다 맞춰요. 전용 초상화(`portraits/`)는 인물의 `face`로 맞춰요.
- 증거를 받으면 알림 아래에 「확인되는 것」 첫 줄이 함께 떠요.

- 캐릭터에 `offscreen: true`를 달면(`characters.ts`) 목소리만 나오고 화면은 그대로예요. 1화의 방대식, 스마트워치, 아이가드가 그래요.
- 증언에 `penalty`를 달면 그 반대신문만 오답 벌점이 달라져요(4화). 1화는 아래 「재검토 기회」를 써요.
- 1화에서 마지막 증언을 지나 첫 증언으로 돌아갈 때는 증언의 `loop` 대사(강단비의 생각이나 나래의 속삭임, 바퀴마다 조금씩 구체적으로)가 나와 한 바퀴가 끝났음을 알려요.
- 선택지·짝짓기·사진 단계에서도 R(또는 법원기록 버튼)로 법원기록을 열 수 있어요.
- 증언을 다 들으면 잠깐 암전되며 "증언 끝"이 뜨고, 증언 전에 흐르던 곡(보통 증인 테마)으로 돌아가 반응 대사(`beforeCross`)가 이어져요.
- 사건에 `crossBgm: 'cross'`를 주면 모든 반대신문이 같은 곡을 써요. `cutMusicOnObjection: true`면 정답 증거를 내미는 순간 음악이 끊기고, 대본에서 증인이 당황하는 줄에 `bgm('objection')`을 넣어 다시 틀어요.
- `present(질문, ['recorder', 'oh'], …)`처럼 정답을 여러 개 줄 수 있어요. 다섯째 인자로 `{ 증거id: [대사] }`를 주면 맞는 방향이지만 아직 모자란 증거를 감점 없이 받아 줘요(반대신문의 `nearMiss`와 같아요).
- 정답이 여럿일 때 `ifPresented('doorLog', [...], [...])`로 플레이어가 고른 증거에 맞춰 논증을 시작할 수 있어요.
- `choose('태오에게 묻기', '무엇부터 물어볼까?', [option(…), option(…, [...], true)], 'taeo')` — 선택지. `true`가 붙은 걸 고를 때까지 다른 것도 골라 볼 수 있어요.
- `pinpoint('orot', '어느 출입구?', 'backdoor', [맞았을 때], [틀렸을 때])` — 평면도(`src/engine/maps.ts`)에서 자리를 찍게 해요. 클릭하면 자리를 고르고, 한 번 더 클릭하거나 Enter·「이 자리를 지목한다」로 확정해요. 틀리면 증거를 잘못 냈을 때처럼 벌점이 붙어요.
- 증거에 `map: 'orot'`을 달면 법원기록에서 "평면도 크게 보기"가 생겨요.
- 증거의 `detail` 줄이 `02:50  내용`처럼 시각으로 시작하면 시각이 따로 한 칸으로 정렬돼요. 시각을 비교해야 하는 긴 기록은 `table: { head, rows, quiet }`로 표를 만들 수 있어요(`quiet`에 넣은 줄은 흐리게). 1화의 도어락 기록이 예시예요.
- 반대신문 중 증거를 고를 때는 반박할 증언이 법원기록 맨 위에 고정돼요.
- `memo()`로 적은 줄은 법원기록의 "메모" 탭에 쌓여요(저장에도 남아요). 메모가 하나라도 생기면 탭이 나타나요.
- 증언에 `hints: [[막연한 힌트], [구체적인 힌트]]`를 달면, 증언을 한 바퀴 돌 때마다 또는 H를 누를 때 차례로 나와요. 마지막 힌트는 반복돼요.
- 반대신문 화면에는 "2 / 4" 같은 위치와 이미 흔들어 본 증언 표시가 떠요.

## 판관 예측 · 재검토 기회 · 힌트 (1화)

1화는 틀린 답이 유죄 예측을 올리지 않아요. 예측은 이야기가 정한 값이고, 실수는 따로 센 **재검토 기회**만 줄여요.

```ts
predict(69.1, '02:45 피고인의 매장 알리바이 확인'),       // 예측을 그 값으로 덮어쓰고 이유를 잠깐 보여 줘요
predict(24.0, '머리 손상과 상패 대조 결과 대기', '감정 대기'),  // 셋째 인자는 숫자 아래 상태 배지
showRecord('autopsy'),                                     // 법원기록을 그 증거의 덧붙임 위치로 펼쳐 보여 주기
present('질문', ['autopsy', 'sceneItems'], [맞을 때], [틀릴 때], { share112: [부분 정답] },
  { hints: ['쟁점', '자료', '구체적으로'], hintKey: 'q10' }),   // 여섯째 인자: 힌트 3단계, free(틀려도 기회 안 줄어듦)
choose('제목', '질문', [option(…)], 'dan', { free: true, hints: [...], hintKey: 'q09' }),
pinpoint('orot', '질문', 'desk', [맞을 때], [틀릴 때], { free: true, hints: [...] }),
match({ title, prompt, rows: [{ label, cards: [{ id, time, who, text }] }, { … }],
  answer: [['c44', 'a40']], wrong: { c16: '…', 'c52|a40': '…', default: '…' }, done: '…', confirm: '이 둘을 맞세운다' }, { hints }),
photoTask('share112', { region: { frame, view, prompt, spots, answer, wrong, done },
  frames: { prompt, answer: [1, 2], bothIntact, bothBroken, gap, done }, closing }, { hints }),
```

- `issue('…')`는 기존 대본·저장 호환을 위해 상태만 기록해요. 오른쪽 위 쟁점 UI와 반대신문 힌트 버튼은 표시하지 않아요. 확인된 사실과 남은 질문은 법원기록의 메모에서 볼 수 있어요.
- `dimHud(true)`는 클라이맥스 동안 HUD를 흐리게 하고, `dimHud(false)`로 되돌려요.
- `match`는 두 기록을 위아래 줄의 카드로 놓고, 한 장씩 골라 짝짓게 해요. 정답 쌍을 여러 개 줄 수 있고, 오답은 `위|아래`, 위 카드, 아래 카드, `default` 순서로 찾은 피드백 한 줄만 보여 줘요(기회는 줄지 않아요).
- `photoTask`는 사진 세트의 뷰어 안에서 두 단계를 이어서 해요. 한 장의 사진에서 부분을 지목하고(`spots`, 사진 좌표), 그 부분이 남은 마지막 사진과 사라진 첫 사진을 고르면 확대와 감정 도식이 나와요.

- 사건에 `chances: 3`, `hintMode: 'manual'`, `gaugeStatus`를 주면 이 방식이 켜져요(`ep1/case.ts`). 4화처럼 주지 않으면 예전대로 오답이 예측을 올리고 100%면 게임오버예요.
- 증언(`Testimony`)에 `free: true`면 그 반대신문은 틀려도 기회가 줄지 않아요(1화 튜토리얼 두 개). `hintText: [3줄]`이 그 반대신문의 힌트 창 내용이에요.
- 부분 정답(`nearMiss`)은 언제나 차감이 없고, 오답 통계에도 들어가지 않아요.
- 기회가 0이 되면 "기록 보고 이어하기"(법원기록이 열리고 기회 3으로, 같은 자리에서 계속) 또는 "이 심문 처음부터"를 고르게 해요. 예측값은 그대로예요.
- 힌트는 H나 힌트 버튼을 눌렀을 때만 열려요. 몇 단계까지 봤는지는 저장되고, 엔딩 카드에 "열어 본 힌트 N단계"로 나와요. 반대신문을 한 바퀴 다 돌면 "필요하면 H로 힌트를 볼 수 있어요"가 한 번만 떠요.
- 설정(O)에는 "현재 심문 처음부터"(1화 반대신문 중)와 "사건 기록부로"가 있어요.
- 재검토 기회는 법정에서 재판이 진행되는 동안에만 보여요. `field(...)`로 법정 밖에 나가 있을 때와 `verdict` 뒤에는 숨겨요(지금의 쟁점도 법정 밖에서는 숨겨요).

## 증거 카드 (1화)

```ts
{
  id: 'share112', name: '112 현장 공유 사진', label: '증 제7호',
  source: '112 종합상황실 서버 …',          // 출처
  proves: ['…'], limits: ['…'],             // 확인되는 것 / 이것만으로는 알 수 없는 것
  photos: 'share112',                       // src/engine/photos.ts의 사진 세트. 두 장 비교 + Space로 크게 보기
  detail: ['[최초 신고]', '02:55:05  …', '▷ 수사 의견: …'],  // [..] 줄은 구역 제목과 바로가기, ▷ 줄은 의견(인용 상자)
}
```

- 새로 받은 증거에는 "새로", 덧붙임(`annotate`)이 생긴 증거에는 "갱신" 배지가 붙고, 열어서 덧붙임까지 보면 사라져요.
- 증거에 `group: '녹음·통화'`처럼 선반을 주면 법원기록이 선반별로 묶어 보여 줘요(선반 순서는 증거 목록에 처음 나온 순서).
- 사진 세트의 배경 그림은 `src/assets/photos/<이름>.png`예요. 모든 장이 같은 배경을 쓰고, 달라지는 물건만 SVG로 얹어서 구도가 어긋나지 않아요.
- 메모(`memo`)를 적으면 "✎ 수첩에 적었다"가 잠깐 떴다 사라지고, 연달아 적으면 "2줄"처럼 묶어서 세요. 안 읽은 메모 수는 법원기록의 메모 탭에 남아요.
- `flag('photomark:share112')`를 켜면 사진 세트의 "대응 영역 표시"(점선 사각형)를 켤 수 있어요. 1화는 오후 4시 감정 뒤에 켜요.

## 저장

진행 상황은 이 브라우저에 자동으로 저장돼요(`localStorage`, 사건마다 한 칸). 타이틀에서 **이어하기**를 누르면 이어서 해요.

| 저장되는 때 | 이어하면 |
|---|---|
| 각 장면 시작 (조사, 개정, 반대신문 1·2, 마지막 증거 제시) | 그 장면 처음부터 |
| 조사 메뉴가 뜰 때마다 | 그 장소의 메뉴로. 이미 본 대사·모은 증거·플래그는 그대로 |
| 반대신문에서 증언 한 줄을 볼 때마다 | 「반대신문 재개」로 같은 증언부터. 드러난 증언, 유죄 예측률도 그대로 |

- 대사 기록(L)의 최근 120줄도 함께 저장돼요. 이어하면 "여기서부터 이어서 진행" 줄 위로 지난 대사가 보이고, 이어하기 화면에는 수첩의 최근 메모 두 줄이 떠요.
- 에피소드를 끝까지 보면 저장이 지워져요.
- `?scene=` 로 건너뛰어 시작하면 저장하지 않아요. 테스트 때문에 진짜 저장이 덮어써지지 않게요.
- 대본을 크게 고쳐서 예전 저장이 맞지 않게 되면 그 화의 `id`(`case-daon.ts`, `ep1/case.ts`)를 바꾸세요. 예전 저장은 무시돼요. 1화는 `revision`(지금 `EP1-R4`)도 저장에 남겨서, 개정이 다르면 이어하지 않아요. 예전 id를 `legacyIds`에 적어 두면, 아직 해결하지 않은 사람에게 "내용이 개정되었어요" 안내가 한 번 떠요.
- 끝까지 본 화는 사건 기록부에 "해결" 도장이 찍혀요. 해결한 1화를 고르면 "처음부터 하기 / 장면 선택"이 나오고, 장면 선택은 `checkpoints`(CP1~CP8)의 증거·사실·예측으로 시작해요(저장도 평소처럼 돼요).
- 1화는 재검토 기회와 상태 배지도 저장돼요. 설정의 "사건 기록부로"는 저장한 뒤 나가고, 저장이 안 되면 확인 카드를 띄워요.

## 소리

모든 소리는 WebAudio로 합성해요. 파일이 없어도 돼요.

- **배경음악** (`src/engine/music.ts`): 타이틀 테마, 법정·증언·반대신문·추궁·진범 추궁·긴장·다온 테마·조사(로비/고객센터/서버실)·슬픔·무죄·에필로그, 1화의 새벽 편의점(`night`)·오정택 테마(`oh`)·정(情) 테마(`jeong`)·엄정한 테마(`eom`)·반전(`objection`)·대기실(`waitroom`)·후반 반대신문과 증언(`crossTense`·`testimonyTense`, 같은 동기의 긴장 변주)·진상 직전(`climax`)·추궁(`pursuitTruth`, 타이틀 동기를 펼친 마지막 한 방). 증언에 `hearing`·`crossBgm`을 주면 그 반대신문만 곡이 바뀌어요. 음표를 글자로 적는 악보 형식이라 대본처럼 고칠 수 있어요.
- **환경음**: 법정, 로비, 고객센터(시계 초침), 서버실(팬 소리), 대기실, 편의점(냉장고 소리), 밤 골목, 녹음기 잡음.
- **효과음**: 책상 치기, 깨달음 차임, 충격 스팅, 방청석 웅성거림, 발소리, 문, 타자 소리, 편의점 문 차임, 스마트워치 알림, 셔터, AI 감지 경고, 녹음기 재생, 둔탁한 충돌 등. `sfx('realize')`처럼 대본에 넣어요.
- 설정(O)의 음악·효과음 크기는 0~10, 기본 8이에요.
- 자동으로 나는 소리: 표정이 `shock`·`panic`일 때 충격 스팅, 강단비가 `point`로 말할 때 책상 치는 소리, 장소를 옮길 때 발소리.
- 증언을 처음 듣는 동안은 증언용 곡(`hearing`, 기본 `testimony`)이, 반대신문이 시작되면 장면의 곡이 나와요.
