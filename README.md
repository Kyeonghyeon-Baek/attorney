# 판 뒤집기

근미래 서울(2031년)을 배경으로 한 법정 추리 게임. 타이틀의 **사건 기록부**에서 에피소드를 골라요.

**제1화 「무인(無人)의 밤」** (약 35~45분, 법정만): 무인 편의점 창고에서 점주가 숨지고, 감시 AI가 "상품 무단 반출"로 찍은 야간 관리원이 피고인이 된다. 범인을 먼저 보여 주는 프롤로그로 시작하는 튜토리얼 에피소드.

1. 프롤로그 「그날 밤」: 감시 카메라 화면과 범인 시점 (약 3분)
2. 피고인 대기실: 나래, 태오, 구만두, 엄정한 첫 등장 (약 5분)
3. 구만두의 사건 개요 (튜토리얼 반대신문) → 목격자 오정택의 "봤다", "들었다"
4. 태오의 침묵 → 휴정 → 조말순 할머니, 폐기 삼각김밥 봉지, 녹음기 재생
5. 오정택의 "기계가 증명합니다", "창고 안은 모릅니다" → 스마트워치 → 진범 붕괴 → 무죄 → 에필로그

**제4화 「대체된 증인」** (약 40분, 조사 + 법정 3일): 누리랩 조사 → AI 증인 다온 → 박하은 → 서지훈 신문, 진범 붕괴, 무죄, 에필로그.

제2화, 제3화는 사건 기록부에 "준비 중"으로 나와요.

## 실행

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:5173`을 열면 돼요.

| 주소 뒤에 붙이기 | 하는 일 |

## 조작

| 키 | 하는 일 |
|---|---|
| 클릭 · Enter · Space | 다음 대사 |
| Q | 흔들기 (증언을 캐묻기) |
| H | 반대신문 힌트 (막연한 것부터 차례로) |

| R | 법원기록 보기 |
| L | 대사 기록 (지나간 대사 다시 보기) |

## 대본 쓰는 법

```ts
say('eom', '반박의 여지가 없는 기록입니다.'),
say('dan', '그 사원증은 {r}회사 안에{/} 있었어요!', 'point'),   // {r}…{/} 빨간 강조, 마지막 인자는 표정
think('(…뭔가 이상해.)'),                                     // 주인공 속마음 (파란 글씨)
shout('objection'),                                            // 이의 있음! / holdit 잠깐! / takethat 받아라!
```

증언 한 줄에는 `press`(흔들었을 때 대사), `accept`(모순이 되는 증거나 인물), `nearMiss`(아깝지만 오답일 때 힌트, 감점 없음)를 달 수 있어요. 지적 자체는 맞는데 아직 결정타가 아닐 때는 `nearMiss`에서 그 지적을 먼저 인정하고 `memo()`로 남긴 다음, 남은 질문을 짚어 주세요. 필요하면 `reveal()`로 증언을 고쳐 말하게 하고, `flag()`·`when()`으로 뒤의 대사가 그 사실을 기억하게 해요(1화 「창고 안은 모릅니다」의 도어락). `accept`에 인물 id(예: `'seo'`)를 넣으면 법원기록의 "인물" 탭에서 그 사람을 제시해야 해요. 숨겨진 증언(`hidden`, `replaces`)은 흔들기 도중 `reveal()`로 드러나요.

## 조사 파트 쓰는 법

장소 하나는 이렇게 생겼어요 (`src/content/investigation.ts`).

```ts
callcenter: {
  name: '고객센터',
  bg: 'callcenter',                 // src/assets/bg/callcenter.png
  person: undefined,                // 그 장소에 있는 사람. 있으면 대화하기·제시하기가 켜져요
  connects: ['lobby', 'serverroom'],
  enter: [...],                     // 처음 도착했을 때 한 번만
  hotspots: [
    { id: 'ramen', label: '컵라면', x: 935, y: 438, w: 145, h: 112,   // 1280×720 기준 좌표
      script: [..., flag('f_ramen')],
      again: [...] },               // 두 번째부터
  ],
  talks: [{ id: 'nightshift', label: '밤에 일하는 사람', requires: 'f_ramen', script: [...] }],
  presents: { cardReturn: [...] },  // 증거별 반응
}
```

- `addEvidence('id')` — 증거를 법원기록에 넣고 알림을 띄워요
- `flag('이름')` — 진행 상황을 기록해요. `requires`나 `when()`으로 확인해요
- `when('id', [있을 때], [없을 때])` — 플래그나 증거를 가졌는지에 따라 갈라져요
- `addProfile('id')` — 나중에 등장하는 인물(`later: true`)을 법원기록에 넣어요
- `field('lounge')` … `field(null)` — 메뉴 없이 법정 밖 장소(대기실 등)를 보여 줬다가 법정으로 돌아와요
- `zoom` · `redflash` — 진범이 무너질 때처럼 카메라를 당기고 화면을 붉게 번쩍여요
- `verdict('무죄', true)` — 판결을 한 글자씩 찍고, 무죄면 색동 꽃가루와 환호가 터져요
- `investigate('lobby', [목표들], [끝날 때 대본])` — 목표(증거·플래그)를 전부 모으면 조사가 끝나요

## 연출 명령 (1화에서 추가)

```ts
episode('제1화', '무인(無人)의 밤'),          // 에피소드 타이틀 카드
hud(false),                                   // 프롤로그처럼 HUD(게이지·버튼)를 숨김. hud(true)로 복구
field('lounge', true),                        // 법정 밖 장소. true면 단비·나래도 화면에 나와요
tint('night'),                                // 배경과 인물을 밤 조명으로. tint(null)로 복구
cg('alley'), cg(null),                        // 이벤트 CG (src/assets/cg). 사람이 그려진 한 장짜리 그림
cctv('CAM1 매장', '2031.03.15 02:31:07', '아이가드 · …'),  // 감시 카메라 화면. 시계가 저절로 흘러요
detect(box('관리원 · 신태오', 815, 128, 400, 560), box('폐기 대상', 1150, 300, 120, 250, true)),  // AI 감지 상자 (true면 빨간 경고)
cctvOff,
tape('방대식의 녹음기 · 0315_0236'),           // 녹음기 재생 화면
rec('bang', '02:36:04', '…보여? 녹음기야.'),   // 녹음 속 대사 (시각이 화면에 떠요)
recNote('02:41:02', '(쿵!)'),                  // 녹음 속 소리
tape(null),
introduce('oh', '오롯리테일 운영지원팀 슈퍼바이저'),  // 증인 이름판
note('「재개정합니다.」'),                     // 이름 없는 안내·내레이션
addEvidenceSet('경찰 수사 기록', 'iguardLog', 'autopsy'),  // 증거 여러 개를 한 번에
revise('taeo', '…무죄 판결을 받았다.'),        // 법원기록 설명 고쳐 쓰기
pulse,                                        // 판관 게이지를 두근거리게
fadeOut, place('새벽 2시 36분', '창고'), fadeIn,  // 암전 → 시간 카드 → 다시 밝게
board('그날 새벽의 시간표', [row('02:00', '셔터 내림'), row('02:50~02:52', '검찰 주장', 'claim')]), boardOff,
plan('orot', ['storeDoor']), planOff,         // 평면도를 띄우고 영역 강조 (설명용, 클릭 없음)
memo('검찰 주장: 범행은 02:50~02:52'),         // 강단비의 수첩(법원기록 → 메모 탭)에 한 줄
sayAs('oh', '???', '…그거, 이리 주시죠.'),      // 다른 이름표로 말하기
```

- 캐릭터에 `offscreen: true`를 달면(`characters.ts`) 목소리만 나오고 화면은 그대로예요. 1화의 방대식, 스마트워치, 아이가드가 그래요.
- 증언에 `penalty`를 달면 그 반대신문만 오답 벌점이 달라져요. 1화 튜토리얼은 96.4%에서 시작하니 1.1%로 낮췄어요.
- 증언을 다 들으면 잠깐 암전되며 "증언 끝"이 뜨고, 증언 전에 흐르던 곡(보통 증인 테마)으로 돌아가 반응 대사(`beforeCross`)가 이어져요.
- 사건에 `crossBgm: 'cross'`를 주면 모든 반대신문이 같은 곡을 써요. `cutMusicOnObjection: true`면 정답 증거를 내미는 순간 음악이 끊기고, 대본에서 증인이 당황하는 줄에 `bgm('objection')`을 넣어 다시 틀어요.
- `present(질문, ['recorder', 'oh'], …)`처럼 정답을 여러 개 줄 수 있어요.
- `choose('태오에게 묻기', '무엇부터 물어볼까?', [option(…), option(…, [...], true)], 'taeo')` — 선택지. `true`가 붙은 걸 고를 때까지 다른 것도 골라 볼 수 있어요.
- `pinpoint('orot', '어느 출입구?', 'backdoor', [맞았을 때], [틀렸을 때])` — 평면도(`src/engine/maps.ts`)에서 자리를 찍게 해요. 클릭하면 자리를 고르고, 한 번 더 클릭하거나 Enter·「이 자리를 지목한다」로 확정해요. 틀리면 증거를 잘못 냈을 때처럼 벌점이 붙어요.
- 증거에 `map: 'orot'`을 달면 법원기록에서 "평면도 크게 보기"가 생겨요.
- 증거의 `detail` 줄이 `02:50  내용`처럼 시각으로 시작하면 시각이 따로 한 칸으로 정렬돼요. 시각을 비교해야 하는 긴 기록은 `table: { head, rows, quiet }`로 표를 만들 수 있어요(`quiet`에 넣은 줄은 흐리게). 1화의 도어락 기록이 예시예요.
- 반대신문 중 증거를 고를 때는 반박할 증언이 법원기록 맨 위에 고정돼요.
- `memo()`로 적은 줄은 법원기록의 "메모" 탭에 쌓여요(저장에도 남아요). 메모가 하나라도 생기면 탭이 나타나요.
- 증언에 `hints: [[막연한 힌트], [구체적인 힌트]]`를 달면, 증언을 한 바퀴 돌 때마다 또는 H를 누를 때 차례로 나와요. 마지막 힌트는 반복돼요.
- 반대신문 화면에는 "2 / 4" 같은 위치와 이미 흔들어 본 증언 표시가 떠요.

## 저장

진행 상황은 이 브라우저에 자동으로 저장돼요(`localStorage`, 사건마다 한 칸). 타이틀에서 **이어하기**를 누르면 이어서 해요.

| 저장되는 때 | 이어하면 |
|---|---|
| 각 장면 시작 (조사, 개정, 반대신문 1·2, 마지막 증거 제시) | 그 장면 처음부터 |
| 조사 메뉴가 뜰 때마다 | 그 장소의 메뉴로. 이미 본 대사·모은 증거·플래그는 그대로 |
| 반대신문에서 증언 한 줄을 볼 때마다 | 「반대신문 재개」로 같은 증언부터. 드러난 증언, 유죄 예측률도 그대로 |

- 대사 기록(L)의 최근 120줄도 함께 저장돼요. 이어하면 "여기서부터 이어서 진행" 줄 위로 지난 대사가 보이고, 이어하기 화면에는 수첩의 최근 메모 두 줄이 떠요.
- 에피소드를 끝까지 보면 저장이 지워져요.
- `?scene=` 로 건너뛰어 시작하면 저장하지 않아요. 테스트 때문에 진짜 저장이 덮어써지지 않게요.
- 대본을 크게 고쳐서 예전 저장이 맞지 않게 되면 그 화의 `id`(`case-daon.ts`, `ep1/case.ts`)를 바꾸세요. 예전 저장은 무시돼요.
- 끝까지 본 화는 사건 기록부에 "해결" 도장이 찍혀요.

## 소리

모든 소리는 WebAudio로 합성해요. 파일이 없어도 돼요.

- **배경음악** (`src/engine/music.ts`): 타이틀 테마, 법정·증언·반대신문·추궁·진범 추궁·긴장·다온 테마·조사(로비/고객센터/서버실)·슬픔·무죄·에필로그, 1화의 새벽 편의점(`night`)·오정택 테마(`oh`)·정(情) 테마(`jeong`)·엄정한 테마(`eom`)·반전(`objection`). 음표를 글자로 적는 악보 형식이라 대본처럼 고칠 수 있어요.
- **환경음**: 법정, 로비, 고객센터(시계 초침), 서버실(팬 소리), 대기실, 편의점(냉장고 소리), 밤 골목, 녹음기 잡음.
- **효과음**: 책상 치기, 깨달음 차임, 충격 스팅, 방청석 웅성거림, 발소리, 문, 타자 소리, 편의점 문 차임, 스마트워치 알림, 셔터, AI 감지 경고, 녹음기 재생, 둔탁한 충돌 등. `sfx('realize')`처럼 대본에 넣어요.
- 설정(O)의 음악·효과음 크기는 0~10, 기본 8이에요.
- 자동으로 나는 소리: 표정이 `shock`·`panic`일 때 충격 스팅, 강단비가 `point`로 말할 때 책상 치는 소리, 장소를 옮길 때 발소리.
- 증언을 처음 듣는 동안은 증언용 곡(`hearing`, 기본 `testimony`)이, 반대신문이 시작되면 장면의 곡이 나와요.
