# 판 뒤집기

근미래 서울(2031년)을 배경으로 한 법정 추리 게임. 지금 들어 있는 건 제4화 「대체된 증인」 프로토타입이에요. 재판 전날 누리랩을 조사하고(약 5분), 다음 날 법정에서 다온을 반대신문해요(약 5~8분).

## 실행

```bash
npm install
npm run dev
```

브라우저에서 `http://localhost:5173`을 열면 돼요.

| 주소 뒤에 붙이기 | 하는 일 |
|---|---|
| `?scene=intro` | 조사를 건너뛰고 법정부터 시작 (증거는 전부 가진 상태, 저장 안 함) |
| `?scene=cross1` | 첫 번째 반대신문부터 시작 |
| `?scene=cross2` | 두 번째 반대신문부터 시작 |
| `?scene=climax` | 마지막 증거 제시부터 시작 |
| `?fast` | 대사를 즉시 출력 (테스트용) |
| `?spots` | 조사 포인트 위치를 빨간 테두리로 표시 (배경을 바꿨을 때 위치 맞추기용) |

## 조작

| 키 | 하는 일 |
|---|---|
| 클릭 · Enter · Space | 다음 대사 |
| Q | 흔들기 (증언을 캐묻기) |
| E | 증거 제시 |
| ← → | 증언 이동 |
| R | 법원기록 보기 |
| M | 소리 켜기·끄기 |
| 1~4 | 조사 메뉴(조사·이동·대화·제시)나 질문 재구성 메뉴에서 고르기 |
| Esc | 조사·목록·법원기록 닫기 |

## 구조

```
src/
  content/              ← 시나리오. 사건을 새로 쓸 때는 여기만 고치면 돼요
    case-daon.ts          제4화: 증거, 인물, 증언, 장면 대본
    investigation.ts      제4화 조사 파트: 장소, 조사 포인트, 대화 화제, 증거 제시 반응
    characters.ts         캐릭터 이름, 위치, 목소리
    script.ts             say() · think() · ask() 같은 대본용 함수
  engine/               ← 게임 엔진
    game.ts               대본 실행, 반대신문, 증거 제시, 게임오버
    stage.ts              배경, 캐릭터, 책상, 다온 모니터
    textbox.ts            한 글자씩 출력되는 대사창
    record.ts             법원기록 (사건 기록철)
    ask.ts                질문 재구성 메뉴
    invest.ts             조사 메뉴, 조사 포인트 고르기, 이동·대화 목록
    gauge.ts              AI 판결 예측 (유죄 확률 = 체력)
    audio.ts              효과음, 대사음, 배경음악 (전부 코드로 합성)
  assets/               ← 그림. 넣기만 하면 자동으로 인식돼요
docs/art-guide.md       ← 그림 규칙과 Codex 프롬프트
```

## 대본 쓰는 법

```ts
say('eom', '반박의 여지가 없는 기록입니다.'),
say('dan', '그 사원증은 {r}회사 안에{/} 있었어요!', 'point'),   // {r}…{/} 빨간 강조, 마지막 인자는 표정
think('(…뭔가 이상해.)'),                                     // 주인공 속마음 (파란 글씨)
shout('objection'),                                            // 이의 있음! / holdit 잠깐! / takethat 받아라!
```

증언 한 줄에는 `press`(흔들었을 때 대사), `accept`(모순이 되는 증거), `nearMiss`(아깝지만 오답일 때 힌트, 감점 없음)를 달 수 있어요. 숨겨진 증언(`hidden`, `replaces`)은 흔들기 도중 `reveal()`로 드러나요.

## 조사 파트 쓰는 법

장소 하나는 이렇게 생겼어요 (`src/content/investigation.ts`).

```ts
callcenter: {
  name: '고객센터',
  bg: 'callcenter',                 // src/assets/bg/callcenter.png
  person: undefined,                // 그 장소에 있는 사람. 있으면 대화하기·제시하기가 켜져요
  connects: ['lobby', 'serverroom'],
  enter: [...],                     // 처음 도착했을 때 한 번만
  hotspots: [
    { id: 'ramen', label: '컵라면', x: 935, y: 438, w: 145, h: 112,   // 1280×720 기준 좌표
      script: [..., flag('f_ramen')],
      again: [...] },               // 두 번째부터
  ],
  talks: [{ id: 'nightshift', label: '밤에 일하는 사람', requires: 'f_ramen', script: [...] }],
  presents: { cardReturn: [...] },  // 증거별 반응
}
```

- `addEvidence('id')` — 증거를 법원기록에 넣고 알림을 띄워요
- `flag('이름')` — 진행 상황을 기록해요. `requires`나 `when()`으로 확인해요
- `when('id', [있을 때], [없을 때])` — 플래그나 증거를 가졌는지에 따라 갈라져요
- `investigate('lobby', [목표들], [끝날 때 대본])` — 목표(증거·플래그)를 전부 모으면 조사가 끝나요

## 저장

진행 상황은 이 브라우저에 자동으로 저장돼요(`localStorage`, 사건마다 한 칸). 타이틀에서 **이어하기**를 누르면 이어서 해요.

| 저장되는 때 | 이어하면 |
|---|---|
| 각 장면 시작 (조사, 개정, 반대신문 1·2, 마지막 증거 제시) | 그 장면 처음부터 |
| 조사 메뉴가 뜰 때마다 | 그 장소의 메뉴로. 이미 본 대사·모은 증거·플래그는 그대로 |
| 반대신문에서 증언 한 줄을 볼 때마다 | 「반대신문 재개」로 같은 증언부터. 드러난 증언, 유죄 예측률도 그대로 |

- 에피소드를 끝까지 보면 저장이 지워져요.
- `?scene=` 로 건너뛰어 시작하면 저장하지 않아요. 테스트 때문에 진짜 저장이 덮어써지지 않게요.
- 대본을 크게 고쳐서 예전 저장이 맞지 않게 되면 `case-daon.ts`의 `id`를 바꾸세요. 예전 저장은 무시돼요.
