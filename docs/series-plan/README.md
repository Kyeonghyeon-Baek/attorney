# 「판 뒤집기」 1기 스토리 설계 패키지

작성: 2026-10-23 · 버전: SERIES-R1 · 용도: 제작자 검토 및 Claude 대본·개발 인계

> **핵심 방향:** 단비가 독립적인 세 사건의 누명을 벗긴다. 그러나 사람이 바로잡은 마지막 결과만 판관의 성과로 집계되고 있었다. 단비와 엄정한이 원자료를 요구하면서 네 번째 사건이 발생한다.

이 패키지는 제작자가 대화에서 긍정적으로 선택한 전체 방향을 구체화한 **차기 제작 기준안**이다. 아래의 세부 사건, 새 증거, 수치, 장면은 작성자의 설계 제안이며 모두 제작자가 개별 승인한 내용은 아니다. 아직 게임에 구현하거나 플레이로 검증한 설계가 아니다.

## 읽는 순서

1. [시리즈 바이블](story-bible.md): 전체 진상, 세계관, 인물의 선택, 반전 공개 순서, 복선.
2. [에피소드 설계](episodes.md): 1~4화의 실제 사건, 수사·법정 흐름, 증거와 반론, 결말.
3. [제작·검증 인계](production-guide.md): 기존 코드와 충돌하는 설정, Claude와 GPT의 작업 순서, 리뷰 기준, 남은 검증 과제.
4. [문서 검토 기록](review-notes.md): 별도 검토에서 발견한 문제와 반영 내용. 참고용.

전체 스포일러가 포함돼 있다. 초회 플레이 리뷰어에게는 이 패키지를 읽히지 않는다.

## 문서의 우선순위

- **앞으로 만들 시리즈의 방향:** 이 패키지가 우선한다. 예전 `docs/series-bible.md`의 2~4화 개요와 충돌하면 이 패키지로 개정한다.
- **지금 실행되는 1화의 사실:** `docs/ep1-rewrite.md`와 `src/content/ep1/records.ts`가 기준이다. 이 패키지는 1화 살인의 시각·흉기·증거를 바꾸지 않는다.
- **지금 실행되는 4화:** 프로토타입이다. 여기서 채택한다고 명시한 내용만 유지한다. 기존 대사·논증·게이지 동작을 최종 사양으로 간주하지 않는다.
- `README.md`와 `CLAUDE.md`는 엔진·DSL·실행법의 기준이다. 이 패키지는 엔진 API 명세를 대체하지 않는다.

## 이번에 고정할 큰 줄기

1. 태오·소윤·가람·순자 모두 살인 혐의는 무죄다. 피고인을 구한 앞선 승리를 취소하지 않는다.
2. 오정택·안태수·나상철은 서로 공모하지 않는다. 서지훈이 앞의 세 살인을 주문하거나 사건을 배당하지 않았다.
3. 서지훈은 1화부터 등장하는 유능한 협력자이며, 4화의 살인범이자 성능 은폐 책임자다.
4. 강명수는 2027년에 이미 재심 무죄를 받았다. 마지막 화는 아버지를 다시 무죄로 만드는 재판이 아니다.
5. 살인 입증, 운영사의 성능 은폐 입증, 제도 개혁은 서로 다른 일이다. 하나를 밝혀 나머지가 자동 해결되지 않는다.
6. 마지막 무죄 선고는 판관이 0%가 되어서 가능해지는 것이 아니다. 계산을 신뢰할 수 없는 상태에서도 법정이 증거로 판단한다.
7. AI가 전부 가짜이거나 악의를 가진 것으로 끝내지 않는다. 실제 기능과 인간의 개입을 정직하게 구분하는 것이 결말이다.

## 제작 범위

권장 순서: **시리즈 합의 → 1화 연결 장면의 소규모 개정 → 2화 → 3화 → 4화.**

이번 요청의 산출물은 문서다. 코드 변경, 이미지 생성, 배포는 포함하지 않는다. 세부 구현 전에 각 화의 지도·사건 시간표·증거 입증표를 구현 스펙으로 내려야 한다. 구체적인 남은 항목은 [제작·검증 인계](production-guide.md#6-대본-구현-전-반드시-닫을-설계-과제)를 본다.
