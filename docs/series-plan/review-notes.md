# SERIES-R1 문서 검토 기록

2026-10-23. 시나리오 구현 계획을 세우는 별도 검토자가 전체 패키지를 읽고, 중요한 의사결정 누락을 검토했다. 실제 게임 플레이나 물리·법의학 검증은 실시하지 않았다.

## 검토 후 반영

| 지적 | 반영 |
|---|---|
| EP3의 음성 조작자는 입증되지만 살인범은 별개일 수 있음 | 피해자 손상 전 통화, 손상 후 캡처, 실제 출입 경로·복도 원본, 학생의 셔틀 영상으로 행위 구간과 접근자를 별도 구성 |
| ‘살아 있었다’는 사실만으로 치명상 전이라고 할 수 없음 | 통화 화면에서 나중에 칼이 꽂힌 부위의 상태가 보이는 것으로 명시. 구도·식별 가능성은 제작 검증 대상 |
| EP4 둘째 날 무죄가 확정되는데 진범을 잡으려고 재판을 끌 위험 | 둘째 날에는 외부 상담 영상만 확인. 손상 시점은 미확정이며 셋째 날 외부 점검 사진·감정으로 상담 전 가해설을 검토 |
| 독립 보관본이 있는데 대표를 막아서 얻을 것이 불명확 | 대표 제출물은 전체 대응표·제외 사유·정정 이력의 대조 자료. 목표는 완전 삭제가 아닌 제출 취소와 검증 지연 |
| 정한이 김밥집에 찾아올 계기가 불명확 | 휴정에서 사건·명수 이름 공개 → 정한 가족관계 공개 → 명수의 동의 → 원기록 공동 확인 |

재검토에서 EP4의 재판 지속 이유, 공개 저지 목표, 가족 연결 계기가 해결되었다는 평가를 받았다. EP3 통화 화면의 부상 전 상태는 재검토의 마지막 지적을 반영했다. 별도 검토 완료를 ‘모든 사건 장치가 검증되었다’는 뜻으로 사용하지 않는다.

## 남은 제작 검증

`production-guide.md` §6의 G항목을 따른다. 특히 이미지에 그려야 할 상태 차이와 현장 물리 구조는 실제 도면·구도·감정 설명을 확정하기 전 대본의 증명으로 간주하지 않는다.

## 파일 확인

문서 내부의 로컬 파일 링크와 코드 펜스 짝을 확인했다. 기존 게임 코드 변경은 이 작업에 포함하지 않았다. 빌드·플레이 검증은 문서 작성만으로 수행했다고 보고하지 않는다.
