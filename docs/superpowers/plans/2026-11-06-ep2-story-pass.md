# 2화 서사 보강 실행 계획

**Goal:** 승인된 서사 수정과 자연스러운 한국어 대사를 반영한다.
**Spec:** ../specs/2026-11-06-ep2-story-pass.md
**Architecture:** 기존 콘텐츠 DSL과 증거를 유지한다. 엔진 변경 없이 X7의 인정 상태와 제시 순서를 바로잡는다.
**Tech Stack:** TypeScript, Vite, node:test, Gemini 4 Argon CLI.

## 제약과 판단
- 작업 시작 시 미커밋 변경이 존재한다. 별도 작업트리로 현재 작업을 누락하지 않고, 저장소 CLAUDE.md의 main 작업 방침에 따라 현 작업 폴더에서 보존하며 수정한다. 커밋·배포하지 않는다.
- 대화의 승인안을 사양으로 사용한다. 대사만의 변경에는 구현을 그대로 따라 쓰는 테스트를 만들지 않는다. X7 분기는 실제 명령 실행 회귀 테스트를 먼저 작성한다.
- Gemini에는 관련 대본과 승인안을 제공하고 한국어 교정안을 요청한다. 증거 논리·분기는 주 에이전트가 검토한다.

## 작업
- [x] 설정 문서에 논증 한계·기록 오판·별도 이사 반영.
- [x] X7 증거 제시 양방향과 재개 상태의 회귀 테스트 실패 확인 → 분기 수정 → 통과 확인.
- [x] Gemini 대사안 반영: 무죄/동기 분리, 79%, 녹음 오판, 반복 축약, SNS 결론, 나래 행동, 이사.
- [x] 사진 아트와 낮 묘사 정합성 확인 및 수정.
- [x] 전체 테스트·타입 검사·빌드와 독립 최종 리뷰.

## 검토 초점
- X7에서 사진 먼저/일지 먼저/연습 기록 먼저/인정 뒤 재개 모두 종료 가능.
- 소윤의 결백이 안태수 동기 입증에 종속되지 않음.
- 79%와 제보 시점이 단독 살의 증명이 아님.
- 조사에서 확보한 정보와 법정 인물의 인지 일치.
- 변경 전의 조사 종료·프레임 퍼즐·저장 회귀가 보존됨.

## 진행 기록
- X7 회귀: 사진 먼저의 조기 바스켓 인정 및 연습 기록 재제출 문제를 테스트로 재현(2 실패) 후 수정. 기존 저장의 조기 인정 상태도 별도 실패 재현 후 구제 경로 추가.
- 모든 증거 제시 순서 120개, 변경 전 저장 재개 포함 5개 신규 테스트 통과. 기존 테스트 포함 22개 통과. 대사 최종 검수 반영 후에도 전체 22개 재실행 통과.
- Gemini CLI 1차 작성안 19개 중 18개 반영. 1개는 바스켓 인정 시점에 대한 코드 분기 수정과 겹쳐 제외; 해당 인정은 사진과 작업 일지를 모두 확인한 뒤로 유지.
- 2차 Gemini 검수 완료: 설명투 문장, 79% 최고점 표현, 배지 읽기와 통화 내용 보관 오판을 다듬었다. 긴 문장은 대사창에 맞게 분리·축약했다.
- 낮 사진은 imagegen으로 원본을 편집. 1536×1024 유지, 간판·타워·간판틀·물탱크 위치와 글자를 눈으로 대조. 코드 SVG 대체 그림도 낮 하늘로 조정.
- 판단: 저장 revision은 유지. X7-1a에서 일지를 받아 주어 예전 저장의 인정 상태에서도 진행 가능하게 한다. 기존 조사 종료·프레임 관련 사용자 변경은 보존한다.

## 최종 검증과 인계
- Gemini 호출: `agy --model gemini-4-argon --effort medium --print` 2회. 1차 대사 작성, 2차 구어체·사실 표현 검수. 파일 직접 편집 대신 교정안을 받아 선별 반영했다.
- 독립 리뷰: 변경 전 파일 스냅샷과 대조, X7 증언 교체 우선순위·옛 저장·소윤 혐의 철회·79% 한계·SNS 보조 역할 확인. 알려진 2차 검수 항목 외 추가 지적 없음.
- 최종 `npm test`: 22/22 통과. 신규 5개 중 1개가 증거 순서 120개를 모두 실행한다.
- 최종 `npm run build`: 타입 검사와 Vite 빌드 성공. `git diff --check` 통과.
- 테스트는 실제 Game.run/exec/visible 분기 실행을 사용하며 UI 경계만 대체한다. 전체 브라우저 플레이 및 localStorage 왕복 검증은 이번 작업에서 하지 않았다.
- 기존 작업 내용 보존. 저장 리비전 유지 및 구버전 인정 상태의 진행 보장. 커밋·푸시·배포 없이 사용자 플레이 확인을 기다린다.
