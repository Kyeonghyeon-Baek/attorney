# 2화 플레이 피드백 반영 계획

사용자 요청: 그림과 정답의 일치, 조사 종료 선택권, 선택 대화 이력 반영, 관련 증거에 대한 납득 가능한 응답, 후반 반복 축약.

- [x] 조사: `investigate`에 선택적 종료 버튼 문구를 추가한다. 2화의 세 조사 구간에 적용하며 다른 화의 자동 종료는 유지한다. 필수 단서 획득 후 남은 대화·조사·이동과 저장·재개를 검증한다.
- [x] 저장: 둘째 날의 오전/검사실 구간은 기존 `d2:call15` 플래그로 구별한다. 재개 시 활성 조건 분기의 조사 위치를 찾도록 하여 전화와 오전 조사를 반복하지 않는다. 기존 저장 형식·리비전은 유지한다.
- [x] 대사: Gemini CLI 제안을 받아 프레임 질문·피드백, `talked:d1realty:log` 분기, 앞선 심문의 `nearMiss`를 적용한다. 인접 증언에서도 관련 증거는 감점 없이 방향을 설명한다.
- [x] 편집: 마지막 공판의 이미 입증된 설명과 후반 반복 농담을 축약한다. 증거·분기·퍼즐·사건 사실·엔딩은 보존한다.
- [x] 검증: 회귀 테스트의 실패→통과, 전체 테스트·타입 검사·빌드, 브라우저에서 종료 버튼과 프레임 퍼즐을 확인한다.

판단: 35초·37초 그림은 각각 접근 중인 얼굴/손과 화면 아래의 손/소매를 명확하게 구분한다. 이미지를 다시 생성하기보다 실제 보이는 차이를 묻는다. 저장소 방침에 따라 현재 main에서 작업하고 사용자 플레이테스트 전에는 커밋하지 않는다. 기존 미추적 `tests/resume-scene.test.mjs`는 보존한다.

검증 결과: 전체 테스트 17개 통과, 타입 검사와 Vite 빌드 성공. 브라우저 검증용 임시 장면에서 경로당·검사실의 종료 버튼과 남은 대화 접근, 숫자 5 종료, 35초 오답 재시도와 37초 정답 진행을 확인했다. 브라우저 콘솔 오류 없음. 독립 코드 리뷰에서 추가 수정 사항 없음. 전체 에피소드 재플레이는 하지 않았다.

대사 출처: 사용자가 파일 제공을 승인한 뒤 `agy --model gemini-4-argon --effort high --print`로 받은 수정안을 선별 적용했다. 그림은 유지했고, 이미지 생성은 필요하지 않았다. 초반 인물 소개, 안태수 친절 회수, 소윤의 보증금 태도, 엔딩·쿠키를 보존했다.
