# 2화 증거 개편 통합 검수

2026-11-06. 사용자 승인에 따라 GPT가 조율·이미지 제작·통합 검수, Claude Desktop이 UI·엔진·콘텐츠 구현, Antigravity의 Gemini가 한국어 문안·독립 검수를 담당했다.

## 반영 범위

- 증거 20개의 기본 설명을 60자 이내로 줄이고 대표 그림과 「자세히 보기」를 배치했다. 상세는 사진·도식·문자·표·문서·시간순 장면으로 나눈다.
- 사진 5장과 정확한 수량·위치를 표시하는 도식 7개를 추가했다. 사진은 획득 대화 중에도 보여 준다. 영상 자료는 실제 영상 재생을 새로 만드는 대신 기존 프레임과 시간순 기록을 사용한다.
- 필수 단서의 첫 전달을 획득·법정 대사에 보완했다. 증언을 확정 사실처럼 쓰거나, 사진 반전·전화번호 연결 등 플레이어가 풀어야 할 결론을 미리 설명하지 않는다.
- 잠긴 상세 쪽과 표지 그림, 갱신 내용의 실제 열람 여부, 부분 제시, 상세 닫기 후 포커스 복귀를 처리했다. 기존 증거·부분 ID 및 저장 형식은 유지한다.

## 교차 검수에서 수정한 사항

- GPT: 잠긴 쪽의 표지 노출, 화면 아래 갱신 내용의 조기 읽음 처리, 잠긴 쪽만 있는 기록의 빈 화면, 존재하지 않는 사진 참조, 관련 없는 쪽으로 이동하는 대본 명령을 수정하도록 요청했다.
- GPT: W3 주소판 고정 볼트 머리 넷과 바닥 앵커 구멍 넷을 구분하고, 사진의 너트·볼트 수, 방수포와 끈 관계, 바스켓 높이·방향을 점검했다.
- Gemini: 최초 진술 순서, W3 앞뒤면, 출입 기록, SNS 접수 도장, 점검 경고 답장, 해제 합의서, 계정 기록 등 대사 전달 공백을 찾아 문안을 제안했다.
- GPT·Claude: 홈캠 시간, 검시의 단정 표현, 끈 상태, 서류 연락처의 정답 선공개 등 제안 문안의 오류를 바로잡았다.
- Gemini: 조건부 부품 요약과 체크포인트 편집 수집 순서의 충돌을 발견했다. Claude가 획득 순서와 체크포인트 모두 최종 합산 요약이 되도록 수정하고 테스트를 추가했다.
- Gemini의 최종 검수 중 서버 회신·감정 사진 초기 요약에 대한 지적은 현재 통합본에 해당하지 않아 적용하지 않았다. 원문 대조 후 검수 문서 정정을 요청했다.

## 화면 확인

GPT가 1280×720 브라우저에서 증거 20개 초기 요약의 실제 높이를 측정했다. 모두 1~2줄이며 말줄임을 사용하지 않는다. Space 상세 열기, 방향키 쪽 이동, Esc 닫기와 버튼 포커스 복귀, 상세 위 지도 열기·닫기, 반대신문 상세 쪽의 제시 버튼이 실제로 제시 연출로 이어짐을 확인했다.

Claude가 844×390에서 touch-layout 클래스를 적용해 초기 요약 20개와 갱신 요약 13개를 측정했다. 모두 1~2줄이고 시트 넘침은 없었다. 표지 그림이 빈칸으로 보이던 배치를 수정했다. 도식 글씨가 작아지는 문제에는 그림만 전체 무대로 확대하는 「크게 보기」를 추가했다. GPT도 확대 후 Esc로 기존 상세 쪽에 복귀하는 동작과 저장된 모바일 화면을 확인했다.

## 최종 자동 검증

- Node 24.22.1에서 테스트 43개 통과.
- `npm run typecheck`, `npm run build`, `npm run build -- --base=/attorney/` 통과.
- 신규 사진 5개 파일명, 신규 도식 식별자와 새 2화 문안이 공개 빌드에 포함되지 않음을 확인했다. 기존 공용 지도 모듈에는 이미 2화 지도가 있었으며 이번 변경 대상이 아니다.
- `git diff --check` 통과. 작업 전 변경의 역방향 적용 검사로 기존 fadeIn 및 회귀 테스트 보존을 확인했다.

실제 휴대폰 터치 조작과 2화 전체의 연속 플레이는 제작자 플레이테스트 대상으로 남긴다. 장면 바로가기를 이용한 확인은 저장을 비활성화한다. 커밋·푸시·배포는 하지 않는다.
