**증거 카드 방식(제작자 피드백)**: 카드 = 증거 이미지 + 설명 1~2줄. 법원기록 UI에서 출처·확인되는 것·알 수 없는 것 칸을 2화부터 없앤다. 엔진 작업: `Evidence`의 `source`/`proves`/`limits`를 선택 항목으로 바꾸고 2화 카드엔 쓰지 않는다. 대신 이미지 확대(Space)와 이미지 속 지목(일부 증거)을 기본으로. **1화 카드도 같은 방식으로 바꿀지는 별도로 정한다.**

## 0.5 1차 구현 기록 (2026-11-06)

- **대본:** `src/content/ep2/` (opening · investigation1 · trial1 · investigation2 · trial2 · finale · recaps · records · case). Claude가 논리·구조와 초안을 쓰고, Gemini가 파일마다 대사를 다시 써서 분량이 약 2배가 됐다(대사 외 명령은 기계로 동일함을 확인). Astra 전체 리뷰(P0 없음, P1 11 · P2 12)와 Gemini 리뷰 2회(전반·후반)를 반영했다.
- **그림(Astra):** 새 인물 8명(표정 포함 41장) · 배경 17 · CG 7 · 증거 20 · 최봉구 사진. 조사 지점 좌표도 Astra가 그림을 보고 정했다.
- **정답이 걸린 사진(`src/assets/photos/`, Astra가 그림):** 남산 기준 사진(`namsan`, 간판 글자가 바로 읽힘), 201호(`room201`, 창틀 금)·302호 입주(`room302real`, 금 없음, 201의 거울 배치), 인증 클립 프레임(`clip31~38`). 감정 리포트의 302호는 따로 그리지 않고 엔진이 201호를 좌우로 뒤집어 쓴다(글자 반전·금 위치가 구조적으로 정확). `engine/plates.ts`는 그림이 없을 때만 코드 그림으로 대신한다. 「이 옥상에선 남산이 안 보인다」가 논증의 축이라 옥상 배경·클립·방 사진에 그려졌던 남산타워를 지웠다. 퍼즐 좌표는 Astra가 잰 값을 무대 좌표로 옮겼다(무대 y = 그림 y × 0.8333 − 66.7). 감정 리포트·입주 사진·서버 회신 카드에 사진 칸이 생겨 눌러서 크게 본다.
- **새 엔진:** 증거 탭(`id#tab`, 취소 가능) · `compare` 겹쳐 보기 · `app` 앱 화면 · `tint('dusk')` · `crossAgain` · 조사 장소 `requires` · `figure('rail')` · 지도 `village`/`happyRoof`/`happySection` · 새 곡 5(`dalbit` `soyoon` `ahn` `shrine` `dusk`) · 효과음 4 · 환경음 3.
- **설계에서 단순화한 것:** Q04 녹음 구간 도구 → 구간 고르기 선택지 / Q11 프레임 뷰어 → 프레임 스틸 + 선택지 / Q13 여섯 고리 `match` → 법정 화면 보드에 고리를 하나씩 잇고 "알리바이로 끊을 수 있는 고리는?" 한 문제(리뷰: 여섯 연속 제출이 복습처럼 늘어짐) / E18 CCTV 타임라인 → 카드 상세 / 판관 동기 비교 패널 → 보드 줄긋기.
- **그림 위치:** 2화 그림 90장은 `src/assets/ep2/`에 있다. 개발 빌드에서만 읽혀서 공개 빌드는 2화 전과 같은 그림 89장만 담는다(빌드로 확인). 2화를 공개할 때 파일을 공용 폴더로 옮기고 `episodes.ts`의 잠금을 푼다.
- **남은 것:** 제작자 플레이테스트, 조사 지점·얼굴 크롭 미세 조정, 커밋.
