# 1화 완성도 개선 — Claude 개발 인계

2026-10-24 · 설계 버전 EP1-Q1 · 대상: 현재 EP1-R4와 시리즈 연결 장면이 들어간 작업 트리

사용자 요청에 따라 작성한 **구현용 제안 사양**이다. 이 문서를 작성하면서 게임 코드나 이미지를 변경하지 않았다. 실제 구현·플레이 검증 완료 보고서가 아니다. 세부 대사, UI 수치와 연출은 작성자의 제안이며, 기존에 사용자가 각각 승인한 값이라는 뜻은 아니다.

## 전달 방법

Claude에게 아래 프롬프트를 전달하면 된다. 이 디렉터리 전체가 저장소에 있어야 한다.

```text
현재 저장소의 제1화 「무인(無人)의 밤」 완성도를 개선해 줘.

먼저 CLAUDE.md와 README.md를 읽고, 다음 문서를 순서대로 읽어:
1. docs/ep1-quality-pass/implementation.md
2. docs/ep1-quality-pass/visual-and-ux.md
3. docs/ep1-quality-pass/verification.md

이 문서들은 지금 요청하는 1화 개정의 구현 기준이다. 기존 docs/ep1-rewrite.md와
충돌하는 부분은 새 문서의 명시적 변경사항을 우선하고, 기존 설계 문서도 함께 갱신해.
시리즈의 장기 설정은 docs/series-plan/을 따른다.

분석이나 계획만 제출하고 멈추지 말고, 문서의 필수 작업을 실제로 구현하고 검증해.
사건의 실제 범인·범행 시각은 유지하되, 법정에서 증명하는 범위는 새 사양대로 고쳐.
특히 ‘상패 파손 10초 = 치명상 발생 10초’ 단정을 제거하고,
태오가 떠난 뒤에도 상처 속 조각이 판에 붙어 있었다는 사실과 복귀까지의 동선을 연결해.
이미 구현된 지도·사진 비교·힌트·수첩은 재사용하고, 중복 시스템을 만들지 마.
이미지의 증거 불일치는 필수로 수정하고, 선택 연출은 필수 작업 완료 뒤에 판단해.
이미지 생성이 필요하면 기존 화풍과 참조 이미지를 사용하고 결과를 직접 확인해.
도구를 쓸 수 없다면 무엇이 미완료인지 명확히 보고하고 임의의 결과로 대체하지 마.

작업 시작 시 git status와 diff를 확인해 기존 사용자 변경을 보존해.
이번 작업과 무관한 오디오·에셋 로더 변경을 되돌리거나 덮어쓰지 마.
에피소드 2~4의 구현은 건드리지 마. 공용 엔진 수정 시 기존 4화 동작은 회귀 확인해.
새 게임 정상 진행, 합리적 오답, 저장/재개, 모바일 가로 화면을 검증하고,
타입 검사·빌드 결과와 실제로 확인한 범위를 보고해.
장면 바로가기는 모든 증거를 주므로 그것만으로 정상 진행 검증을 대신하지 마.
커밋·푸시는 별도 요청 전에는 하지 마.

완료 보고에는 변경 파일, 논리 수정 요약, 이미지 변경, 테스트 결과,
남은 문제와 내가 직접 플레이할 추천 구간을 적어 줘.
```

## 문서 구성과 우선순위

| 문서 | 역할 |
|---|---|
| [implementation.md](implementation.md) | 사건 입증, 장면별 공개 순서, 퍼즐, 대사, 상태·저장 변경 |
| [visual-and-ux.md](visual-and-ux.md) | 기존 그림에서 확인한 불일치, 이미지 제작 지시, UI 동작·가독성 |
| [verification.md](verification.md) | 실행 순서, 반례 검토, 정상 진행·분기·화면 테스트, 완료 조건 |

- 본 패키지는 **이번에 바꿀 항목**에 한해 기존 EP1-R4 문서보다 우선한다. 언급하지 않은 사실·시스템은 유지한다.
- `docs/series-plan/`의 장기 반전과 인물 설정은 유지한다. 서지훈은 1화에서 유능하고 대화가 통하는 협력자로 보인다.
- 실제 범행의 진상과 법정의 입증 범위를 분리한다. 02:55:56 범행은 진상표에 남지만, 자백 전 법정이 그 초를 확정하지 않는다.
- 구현자는 `docs/ep1-rewrite.md`, `docs/art-guide.md`, 관련 바이블에 반영해 사양이 둘로 갈라지지 않게 한다. 역사적 개정 기록은 삭제하지 말고 현재 사양과 구별한다.

## 설계 선택

비교한 대안은 ① 감정에 추가 단정을 넣어 기존 10초 입증을 유지, ② 실제 사건은 유지하고 무죄에 필요한 시간의 선후관계로 입증을 수정, ③ 사건을 전면 재작성하는 것이다. **이 사양은 ②를 채택한다.** ①은 새로운 법의학 설명에 의존하고, ③은 이미 작동하는 음식·녹음·인물 관계를 불필요하게 버린다. 정확한 시각 맞히기보다 증거의 의미를 이해하게 하는 방향이다.

필수 범위는 논리 보강, 초반 정보 재배치, 마지막 추론 선택, 합리적 제시 대응, 증거 그림 정합성, 요청형 도움말, 저장·회귀 검증이다. 새 감정 CG는 선택 사항이다.
